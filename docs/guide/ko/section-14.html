14. Show와 Playlist

File > New WING show... / Open WING show file...에서 Show 편집기를 엽니다. 스냅샷·스니펫·WAV·스트립/FX 프리셋 파일을 추가하고 Scene 이름·순서·삭제·Skip/Link·태그· MIDI 텍스트를 편집합니다. 프리셋 Scene은 목적지와 Scope를 고르며 나중에 Edit scene destination and scope...에서 바꿀 수 있습니다.

Save preset and add scene...은 선택한 대상의 프리셋을 저장하고 Show에 등록합니다. File > Save preset and add to show...도 같은 작업입니다. Scene 등록을 취소해도 이미 저장한 프리셋 파일은 삭제하지 않습니다.

Save/Save as는 참조 파일도 .show 옆에 복사합니다. 누락된 파일이나 같은 이름의 다른 파일이 있으면 먼저 해결하십시오. Load selected scene...은 스냅샷·스니펫·프리셋을 적용합니다. 저장한 Show를 활성화하려면 콘솔에서 여십시오. File > Console show and scenes는 콘솔에 열린 Show와 Scene 작업을 표시합니다.

File > New WING playlist... / Open WING playlist...는 .plist를 편집합니다. Add WAV files로 추가하고 Song name·Skip·Stop after this song·Repeat playlist를 설정합니다. Move up/down과 Remove로 순서·항목을 편집합니다. Save는 위치를 고르고 WAV도 함께 복사합니다. 저장 위치 선택을 취소하거나 저장에 실패하면 편집 내용으로 돌아갑니다. 편집창의 Cancel은 변경을 버립니다. 저장한 Playlist는 콘솔에서 여십시오. PC 재생이나 원격 Playlist 활성화 명령은 제공하지 않습니다.
