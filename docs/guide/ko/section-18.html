WING Access · 목차 · English

18. Credits

WING Access는 공개된 WING 제어 프로토콜을 바탕으로 독립적으로 개발한 애플리케이션입니다. 다음 프로젝트와 자료를 구현 및 조작 방식의 참고로 사용했습니다.

개발자: Seongyyeol Jang. 개인 사용자 무료이며 재배포는 금지합니다. 사용 조건을 확인하십시오. 제삼자 구성요소에는 각자의 라이선스가 적용됩니다.

WING 문서

Behringer의 WING 제품군 사용자 매뉴얼과 Patrick-Gilles Maillot의 WING Remote Protocols을 콘솔 기능과 프로토콜 구현의 근거로 사용했습니다. Patrick-Gilles Maillot의 WING tools와 wapi 예제도 프로토콜 예제와 개발 도구로 참고했습니다.

라이브러리와 접근성

Danny Firesnake의 libwing을 수정해 네이티브 프로토콜 및 콘솔 검색 라이브러리로 사용합니다. 오프라인 카탈로그도 libwing에서 제공한 자료입니다. 사용 버전·수정 사항·의존성 라이선스는 포함된 서드파티 고지에서 확인할 수 있습니다.

AZ Accessible OSC (azaosc)와 MXAccess32는 키보드 탐색, 페이지 구성, 접근성 컨트롤의 조작 흐름을 참고했습니다. NV Access의 NVDA와 XVision Technology의 센스리더는 스크린 리더 키맵 및 접근성 구현의 참고 자료로 사용했습니다.

추가 참고 자료

Mixing Station의 WING 문서, WING 소스 태그 문서, Arbor Live의 show-file 프로젝트, wing-snap-types를 호환성과 파일 형식 구현에 참고했습니다. OSARA는 접근 가능한 미터 확인 방식의 참고 사례로 사용했습니다.

이름과 상표는 각 소유자에게 귀속됩니다. 이 표기는 사용 의존성과 참고 자료를 밝히기 위한 것이며 해당 업체나 프로젝트의 보증을 뜻하지 않습니다.
