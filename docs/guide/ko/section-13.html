13. 스니펫

Navigate > Library pages > Snippet recorder를 엽니다. Start recording은 다른 컨트롤러를 포함해 콘솔 전체에서 수신한 변경을 모읍니다. Stop recording은 변경된 각 파라미터의 마지막 값을 유지합니다. Save snippet as...로 .snip을 저장합니다.

Edit recorded items...는 체크한 항목을 남깁니다. Edit > Add current page to snippet은 현재 페이지의 값을 추가하고 Update recorded values는 보관한 항목을 갱신합니다. Open snippet...은 파일을 편집하며 Load snippet은 global safes에 따라 적용합니다.

연결이 끊기면 기록을 멈추고 모은 항목은 유지합니다. 재연결 시 자동 재시작하지 않습니다. 오프라인에서는 연습용 변경을 기록합니다. 닫기 전에 저장하십시오. 스니펫은 파라미터 변경을 보관하며 오디오나 시간에 따른 자동 조작을 기록하지 않습니다.
