8. Routing, Setup과 일괄 편집

소스·출력 패치는 Routing, 콘솔 설정은 Setup, 모니터·토크백·레코더는 해당 페이지에서 조작합니다. 물리 I/O 목록은 연결한 모델을 따릅니다. Options > Offline console model은 연습용 모델을 선택합니다. User Patch > Signal patch > Open source는 원본 소스로 이동합니다.

Actions > Batch routing...:

  1. Select destinations...에서 대상을 체크합니다.
  2. Sequential sources 또는 Same source를 선택합니다.
  3. Source group과 First source를 고르고 Planned patches를 확인합니다.
  4. Apply로 적용합니다. Cancel은 전송하지 않습니다.

Actions > Batch bus feeds...:

  1. Destination bus와 Select sources...에서 목적지·소스를 고릅니다.
  2. Setting을 고르고 값을 입력하거나 선택한 뒤 Enter로 준비합니다.
  3. Apply로 전송합니다.

결과에는 충돌·실패 항목이 표시됩니다. 이미 적용한 변경은 자동으로 되돌리지 않습니다. 선택 이후 외부에서 바뀐 대상은 건너뜁니다.

네트워크 설정의 Stored static IP address·subnet mask·gateway는 DHCP에서도 편집할 수 있습니다. 각 옥텟을 입력하고 Enter로 적용합니다. Static에서는 Stored static이 이름에서 빠집니다. Current IP address는 읽기 전용이며 페이지 진입 또는 Refresh network address로 갱신합니다. 조회 실패는 Unavailable, 오프라인은 Not connected로 표시합니다. 실제 임대 마스크·게이트웨이는 표시하지 않습니다.
