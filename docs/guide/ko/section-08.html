8. Routing, Setup과 일괄 편집

소스·출력 패치는 Routing, 콘솔 설정은 Setup, 모니터·토크백·레코더는 해당 페이지에서 조작합니다. 물리 I/O 목록은 연결한 모델을 따릅니다. Options > Offline console model은 연습용 모델을 선택합니다. User Patch > Signal patch > Open source는 원본 소스로 이동합니다.

모니터 조작은 MONITOR / TALKBACK / OSCILLATOR > Monitors에서 합니다. 이 페이지에 Monitor destination, Dim, Mute, Mono, Swap left and right가 있습니다. 각 레벨, Dim attenuation, Limiter threshold는 Monitor A 또는 Monitor B에서 조절합니다. Pan·Width는 EQ, Polarity invert는 Polarity / delay에 있습니다.

SETUP의 Audio에는 클록, USB 오디오, 뮤트 관련 설정이 있습니다. Audio > Solo system에서 Solo mode, 솔로 탭과 솔로·선택 연동을 설정합니다. General preferences 아래에는 Brightness가, Surface > Metering에는 미터 탭 설정이 있습니다. 페이더·표시 동작은 Surface > Surface preferences, 콘솔 분석기 설정은 RTA settings와 그 아래 RTA display에서 조절합니다.

Console > Batch editing > Routing...에서 목적지 트리를 체크하고 Sequential sources 또는 Same source, Source group과 First source를 고릅니다. 필요하면 Show planned patches를 켜서 확인한 뒤 Apply를 누릅니다. 소스 컨트롤에는 현재 할당이 표시되며, 대상마다 다르면 Mixed로 표시합니다. Use current values는 입력한 라우팅 초안을 버리고 현재 할당을 다시 표시합니다.

Sends...에서는 Bus·Main·Matrix 목적지와 소스 스트립을 고릅니다. 설정 컨트롤에는 현재값이 표시됩니다. 대상마다 값이 다르면 Mixed 또는 체크박스의 혼합 상태로 표시합니다. Keep에서는 값을 변경할 수 없습니다. Set value를 선택한 뒤 편집합니다. Send level과 Send pan은 각 소스의 현재 Fader·Pan을 복사할 수도 있습니다. Apply는 Enter로 확정하지 않은 유효한 숫자 입력도 포함합니다.

Keep인 설정은 적용하지 않습니다. 해당 설정의 초안을 취소하려면 Keep을 선택합니다. 대상을 체크하거나 현재값을 표시하는 것만으로는 변경이 준비되지 않습니다.

Source properties...는 같은 방식으로 소스 속성을 편집합니다. Preamp remote assignments...는 원격 할당과 customization 수신 설정만 다룹니다. Clear remote assignments는 표시된 소스의 Off 초안을 만들며 Apply 전에는 적용하지 않습니다. Customization links...에서는 여러 채널의 customization 링크를 바꿉니다.

대상을 바꿔도 초안은 유지합니다. 지원 범위가 달라 유효하지 않은 설정은 수정한 뒤 Apply를 누르십시오. 적용 전 Cancel은 아무것도 보내지 않으며, 적용 중 Cancel은 미전송 작업을 멈춥니다. 이미 적용된 변경은 유지합니다. 외부 변경으로 중단되면 충돌을 확인하고 Keep 또는 Use current values로 해당 초안을 갱신한 뒤 다시 작업하십시오. 편집하지 않은 컨트롤은 외부에서 변경된 값을 반영합니다.

콘솔 페이더 레이어 페이지의 Edit assignments...는 Slot / Type / Target 목록을 엽니다. Move up/down과 Swap with slot은 두 칸을 교환합니다. Clear slot은 빈칸을, Clear layer는 모든 칸을 Off로 만드는 초안을 준비합니다. Apply는 저장, Cancel은 취소입니다. 이 설정은 애플리케이션의 키보드 레이어와 별개입니다.

Edit network addresses...에서 IP 주소, 서브넷 마스크, 게이트웨이를 전체 주소로 입력하고 Save를 선택합니다. Cancel은 변경하지 않고 닫습니다. DHCP에서는 대화상자의 주소가 Stored static으로 표시되며 계속 편집할 수 있습니다. 저장한 설정을 활성화하려면 Apply network settings를 선택하고 확인합니다. 필요한 경우 새 주소로 다시 연결하십시오. 실제 사용 중인 주소는 읽기 전용 Current IP address에서 확인하고 Refresh network address로 갱신합니다.

Console management

SETUP > Console management를 엽니다. Lock console...을 선택하고 확인하면 콘솔 편집이 잠깁니다. 제목 표시줄과 연결 상태에 locked가 표시됩니다. 값과 미터는 계속 갱신되며 탐색과 로컬 파일 편집은 사용할 수 있습니다.

Unlock console을 선택하거나 Ctrl+Alt+L을 누릅니다. 콘솔에서 해제를 확인한 뒤에만 Console unlocked를 읽습니다. 해제되지 않으면 콘솔에서 원격 쓰기를 허용하거나 잠금을 해제하십시오. 사용자 지정 단축키가 우선하므로 Ctrl+Alt+L을 다른 기능에 지정했다면 Help > Keyboard shortcuts에서 현재 키를 확인하십시오. Options > Application write lock(Alt+L)은 별도의 애플리케이션 설정으로 유지됩니다.

Surface lock에서 콘솔 서페이스의 잠금 상태를 확인합니다. Save console state는 현재 상태를 저장하며, Disable console autosave에서 자동 저장 여부를 설정합니다.

콘솔 페이더 할당

SETUP > Surface > Console fader layers에서 서페이스 영역, 레이어, Fader slot을 차례로 선택합니다. Assignment type을 적용한 뒤 표시된 할당 항목을 설정합니다. 스트립·DCA 대상, Send 소스와 목적지, FX 슬롯은 이름으로 표시됩니다. FX 파라미터와 MIDI 인덱스는 숫자로 입력합니다. MIDI 할당에서는 MIDI value도 표시됩니다.

이 페이지는 콘솔 슬롯을 설정합니다. Faders 페이지, 키보드 레이어와 스트립 북마크는 계속 해당 이름의 논리 스트립을 가리킵니다. 콘솔 할당 페이지에서 저장한 북마크는 그 슬롯의 설정으로 돌아옵니다. 모델별 저장 설정에는 Full-size·Compact·Rack을 표시하며, 물리 I/O와 GPIO 목록은 선택한 모델에 맞춰 표시합니다.
