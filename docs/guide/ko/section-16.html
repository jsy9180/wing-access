16. 연결과 동기화

연결 시 콘솔의 현재 설정을 가져온 뒤 Connected를 표시합니다. 콘솔이나 다른 클라이언트의 변경은 작업 페이지를 옮기지 않고 반영합니다. Options > Announce external changes는 외부 변경의 읽기를 설정합니다.

연결 복구 중에는 변경 전송을 멈춥니다. 복구에 실패하면 Console disconnected를 표시합니다. 연결을 확인하고 File > Connect to console...로 다시 연결하십시오. 확인되지 않은 변경은 자동 재전송하지 않습니다. 미터·스니펫 기록은 자동 재개하지 않으며 같은 실행 세션에 남아 있는 결과는 계속 확인할 수 있습니다.
