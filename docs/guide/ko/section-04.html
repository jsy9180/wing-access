4. 레이어, 북마크와 단축키

레이어와 뱅크

키보드 레이어는 대상을 묶고, 각 뱅크는 8개의 위치를 가집니다. 뱅크를 바꾸면 Shift+F1–F8의 대상이 바뀝니다. 위치 키를 누르기 전까지 작업 페이지와 콘솔 값은 바뀌지 않습니다.

  • Shift+F1–F8: 현재 뱅크의 1–8번 위치를 선택합니다.
  • F7 / F8: 이전 / 다음 뱅크입니다. 처음과 마지막에서는 멈춥니다.
  • F9 / Shift+F9: 사용 가능한 레이어를 다음 / 이전 순서로 순환합니다.
  • F2: 뱅크 선택입니다. 레이어 이름, 뱅크 이름 또는 표시된 범위로 검색하고 항목을 골라 Enter를 누릅니다. Escape는 취소합니다. 페이지·포커스·입력 초안은 유지됩니다.
  • Shift+F11: 작업 위치와 현재 뱅크를 읽습니다.

기본 레이어는 다음과 같습니다.

  • Inputs: Channels 1–8, 9–16, 17–24, 25–32, 33–40, Aux 1–8.
  • Buses: Buses 1–8, 9–16.
  • Main / Matrix: Mains 1–4, Matrices 1–8. Main 뱅크의 5–8번 위치는 비어 있습니다.
  • DCAs: DCAs 1–8, 9–16.
  • Effects: FX 1–8, 9–16.
  • Mute groups: 1–8. 위치를 선택하면 Mute로 이동하며 상태는 바꾸지 않습니다.

예를 들어 F2에서 Inputs — Channels 25–32를 찾아 Enter를 누르고 Shift+F3을 누르면 Channel 27을 선택합니다. Aux도 Inputs 레이어에 속하며 F7로 채널 뱅크로 돌아갑니다. F2는 뱅크만 선택합니다. 페이지나 파라미터를 찾으려면 트리 또는 Ctrl+Alt+F를 사용하십시오.

기본 레이어의 위치 키는 현재 페이지에 따라 동작합니다.

  • 일반 스트립 페이지: 다른 스트립의 대응하는 페이지·컨트롤로 이동합니다.
  • Mix: 목적지를 유지하고 선택한 소스의 Send level로 이동합니다.
  • Sends: 소스를 유지하고 선택한 목적지의 Send level로 이동합니다.
  • Faders: 선택한 스트립의 Fader로 이동합니다.
  • FX: 같은 모델일 때만 대응하는 파라미터 위치를 유지합니다.

Mix·Sends·Faders에서는 사용할 수 있는 기본 뱅크만 표시합니다. 빈칸이나 사용할 수 없는 칸 때문에 위치 번호를 당기지 않으며, 해당 위치를 누르면 포커스를 유지합니다. 이 페이지를 열면 포커스한 대상에 맞는 뱅크가 선택됩니다. Tab이나 외부 값 갱신은 뱅크를 바꾸지 않습니다. 제한된 문맥에서 빠져나오려면 Ctrl+` 후 F2를 누르십시오. 실행할 때는 Inputs — Channels 1–8로 시작합니다.

사용자 레이어

사용자 레이어에는 원하는 순서로 스트립·FX 슬롯·뮤트 그룹을 배치합니다. 모든 페이지에서 사용할 수 있으며 Mix·Faders에서도 등록한 스트립의 Home, FX 슬롯 또는 뮤트 그룹으로 바로 이동합니다. 현재 페이지를 기준으로 Send level을 선택하는 기능은 아닙니다.

작업하면서 레이어를 만들려면 다음 순서로 진행합니다.

  1. 대상에 포커스하고 Ctrl+Alt+U를 누릅니다.
  2. 처음에는 사용자 레이어를 선택합니다. 레이어가 없으면 이름을 입력해 만듭니다.
  3. 다른 대상에서도 Ctrl+Alt+U를 누릅니다. 첫 빈칸에 추가하고 모두 차면 새 뱅크를 만듭니다. 이미 등록한 대상이면 기존 위치를 읽습니다.

Mix에서는 포커스한 소스, Sends에서는 목적지, Faders에서는 해당 스트립을 추가합니다. Options > User layers > Quick-add layer에서 이후 빠른 추가에 사용할 레이어를 바꿀 수 있습니다. 사용자 위치로 이동한 뒤에도 선택했던 사용자 뱅크는 유지됩니다.

Options > User layers > Edit user layers...에는 New, Rename, Delete layer, Copy current bank가 있습니다. Add targets는 여러 대상을 고르는 체크 트리를 엽니다. 위치 목록은 Bank / Slot / Target 순서입니다. Clear slot은 빈칸을 남깁니다. Move up/down, Ctrl+Up/Down과 Move to는 두 칸을 교환하며 다른 칸을 당기지 않습니다. 편집창에서는 같은 대상을 여러 번 추가할 수 있습니다. OK는 저장, Cancel은 전체 편집 취소입니다. 특정 페이지나 파라미터를 저장할 때는 사용자 레이어 대신 북마크를 사용하십시오.

북마크

북마크는 값이 아니라 페이지와 포커스한 컨트롤을 저장합니다. 총 10개이며 숫자 키패드가 아닌 키보드 윗줄을 사용합니다. Bookmarks에서 이동하고 Save current location 하위 메뉴에서 저장할 수 있습니다. 저장한 파라미터를 사용할 수 없으면 해당 페이지로 이동합니다.

단축키 편집

Options > Edit keyboard shortcuts...에는 미지정 명령을 포함한 전체 카탈로그가 있습니다. 분류 트리나 Find command로 명령을 찾습니다. 명령 선택 후 New shortcut에서 원하는 키 조합을 누르고 Assign을 선택합니다. Remove shortcut은 미지정으로 바꿉니다. 페이지별 명령은 이름에 표시된 페이지에서 동작합니다.

충돌 창은 영향을 받는 명령을 표시합니다. 덮어쓰면 기존 명령의 키가 해제되고 다른 키를 자동 배정하지 않습니다. Restore selected default는 선택한 명령 하나를, Restore to defaults는 확인 후 전체를 초기화합니다. OK는 저장, Cancel은 편집 취소입니다. 스크린 리더 충돌 경고는 외부 키 설정을 바꾸지 않습니다. 양쪽 키 배정을 확인하십시오.

Options > Main shortcut destination은 Shift+F12 등 Selected Main 명령이 사용할 Main 1–4를 고릅니다. 라우팅은 바뀌지 않습니다. F1은 현재 사용자 배정을 표시하고, HTML 단축키 카탈로그는 기본 배정을 표시합니다.
