11. 스냅샷과 Scope

File > Snapshots > Save WING snapshot as...는 현재 설정을 .snap으로 저장합니다. 오프라인에서는 연습용 설정을 저장합니다. Update current snapshot은 파일을 갱신하고 .bak 백업을 남깁니다. Update scope에서 이번에 갱신할 내용을 선택합니다. File > Snapshots > Edit snapshot scope...는 값을 불러오지 않고 파일의 Scope만 편집합니다.

File > Snapshots > Load WING snapshot...에서 Normal Load 또는 Restore all values를 고릅니다. Scope와 연결·출력 라우팅·Phantom 포함 여부를 확인하고 적용하십시오. Normal Load는 현재 global safes와 클록 설정을 유지합니다. Restore all values는 저장된 Scope와 global safes를 무시하며 파일의 보호·클록 설정도 적용할 수 있습니다.

Ignore global safes는 이번 Load에서만 현재 safes를 무시합니다. Load와 Update에서 임시로 선택한 Scope는 파일의 저장된 Scope를 바꾸지 않습니다.

Scope는 대상·내용을 고르는 체크 트리입니다. Space는 해당 항목과 하위를 체크합니다. 일부 선택된 가지는 선택 개수를 표시하며 내용 선택은 체크한 스트립에 적용합니다. OK는 선택을 확정하고 Cancel은 유지합니다.

불러오기 중에도 관련 없는 컨트롤은 조작할 수 있습니다. 적용 대상 컨트롤은 잠시 차단됩니다. 중단되거나 적용할 수 없는 항목이 있으면 결과를 확인하십시오. 이전 변경이 적용된 상태일 수 있으며 자동으로 되돌리지 않습니다.
