2. 탐색

메인 창은 탐색 트리 하나와 선택한 페이지의 컨트롤로 구성됩니다. 방향키로 트리를 탐색하고 Tab으로 컨트롤을 순서대로 이동합니다. Shift+Tab은 반대 방향입니다. 실행할 때마다 트리는 모두 접힌 상태로 Channels에서 시작합니다.

  • Ctrl+1: 현재 페이지의 트리 항목으로 이동합니다.
  • Ctrl+2: 현재 경로를 유지하고 다른 가지를 접습니다.
  • Ctrl+`: 페이지에서 벗어나 트리를 모두 접고 해당 최상위 항목으로 이동합니다.
  • Ctrl+PageUp / Ctrl+PageDown: 이전 / 다음 스트립의 대응하는 페이지·컨트롤로 이동합니다.
  • Shift+PageUp / Shift+PageDown: 같은 계층의 이전 / 다음 페이지로 이동합니다.
  • Ctrl+Alt+F: 알려진 이름 또는 정확한 파라미터 경로로 검색합니다.
  • F5: 현재 페이지를 새로 고칩니다. F6: 포커스한 값을 읽습니다.
  • Shift+F11: 현재 작업 위치와 키보드 뱅크를 읽습니다.

레이어나 북마크로 이동하면 목적지 컨트롤에 포커스합니다. Ctrl+1은 그 페이지의 트리 항목으로 이동합니다. 단축키로 다른 곳에 이동하면 대상과 변경된 페이지 정보를 읽습니다. 같은 대상·페이지 안에서는 단축키와 Tab 모두 짧은 컨트롤 이름을 읽습니다.

콘솔의 화면 선택은 앱의 작업 페이지를 바꾸지 않습니다. Ctrl+F2는 콘솔에서 선택한 스트립으로 이동합니다. Console > Select this strip on the console은 반대로 콘솔의 선택을 맞춥니다. 이름 검색은 앱에 알려진 페이지를 대상으로 합니다.
