6. 프로세싱과 FX

스트립을 펼치면 EQ·Gate·Dynamics·Insert 등의 페이지가 나타납니다. 모델을 적용하면 해당 컨트롤이 표시됩니다. Tilt EQ는 EQ, High-cut은 Home에 있습니다.

Effects에서 슬롯을 펼치고 Model을 적용한 뒤 Parameters를 엽니다. Model이 None이면 Parameters는 표시하지 않습니다. 파라미터 페이지는 선택한 모델을 따릅니다. Insert 경로는 스트립의 Insert 페이지에서, FX 모델과 wet/dry는 해당 FX 페이지에서 설정합니다. 슬롯이 지원하는 모델과 컨트롤을 표시합니다. 프로세서 전체를 저장하거나 불러오려면 12장의 프리셋 기능을 사용하십시오.

콘솔에 연결한 상태에서 VSS3의 Parameters > Preset을 선택한 다음 Load를 실행하면 선택한 콘솔 내장 프리셋을 불러옵니다.

탭 템포: FX 슬롯의 Home·Parameters·Routing 페이지에서 원하는 박자로 Alt+T를 두 번 이상 누릅니다. 첫 입력으로 측정을 시작하고 이후에는 직전 입력과의 간격을 적용합니다. 키를 길게 누르는 동작은 반복 탭으로 처리하지 않습니다. 4초보다 오래 쉬면 다음 입력부터 다시 시작합니다. 현재 슬롯만 지원 범위 안에서 바뀝니다.

지원 모델: DELAY/REVERB, STEREO DELAY, ULTRATAP DELAY, TAPE DELAY, STEREO CHORUS, STEREO FLANGER, TREMOLO/PANNER, PHASER, MOOD FILTER. 다른 모델에서는 탭 템포를 사용할 수 없다고 알리고 기존 값을 유지합니다.
