17. 설정, 업데이트와 문제 해결

설정·단축키·북마크·사용자 레이어·최근 콘솔은 패키지 안의 user-data/settings.json에 저장합니다.

업데이트하거나 폴더를 옮기려면 다음 순서로 진행합니다.

  1. 앱을 종료하고 새 패키지를 쓰기 가능한 폴더에 풉니다.
  2. 이전 패키지의 user-data와 library를 복사합니다.
  3. 새 bin\WingAccess.exe를 실행합니다. 파일을 확인할 때까지 이전 사본을 보관하십시오.

설정 파일이 손상되면 settings.json.bak를 사용합니다. 둘 다 읽을 수 없으면 기본값을 사용합니다. 기본값으로 시작하려면 앱을 닫고 settings.json과 settings.json.bak를 user-data 밖으로 옮기십시오. 저장에 실패하면 오류를 표시하며 임의로 저장 위치를 바꾸지 않습니다.

키가 동작하지 않으면 F1과 Options > Edit keyboard shortcuts에서 스크린 리더 충돌까지 확인합니다. 편집 중 모델·소스가 바뀌었으면 F5로 새로 고칩니다. 컨트롤을 사용할 수 없으면 해당 페이지와 현재 설정을 확인합니다. 파일 저장이 안 되면 폴더 권한과 누락·충돌하는 참조 파일을 확인하십시오.

문제 제보에는 앱 버전, 콘솔 모델·펌웨어, 페이지·컨트롤, 재현 순서와 오프라인에서도 발생하는지를 적어 주십시오. 진단 자료를 공유하기 전 개인 주소와 Show 내용을 확인하십시오.
