3. 값 편집

슬라이더는 위쪽·오른쪽 화살표로 올리고 아래쪽·왼쪽 화살표로 내립니다. Fader와 Send level은 0.1 dB, PageUp/PageDown은 1 dB, Shift+방향키는 0.01 dB씩 움직입니다. 그 밖의 슬라이더는 컨트롤별 간격을 사용하며 PageUp/PageDown은 그 간격의 10배입니다. Home/End는 최솟값/최댓값으로 이동합니다. Shift+PageUp/PageDown은 페이지 이동입니다.

슬라이더에서 바로 입력하면 새 값으로 바꾸고, Enter를 먼저 누르면 현재값을 편집합니다. Enter로 적용하고 Escape로 취소합니다. 페이더 최솟값은 -inf로 입력할 수 있습니다. 편집 중 Ctrl+A/C/V/X/Z를 사용할 수 있습니다. Tab으로 나가도 미완성 입력은 적용되지 않습니다. 마우스로 슬라이더를 끌면 버튼을 놓을 때 적용합니다.

단위는 생략할 수 있습니다. 주파수에 12600 또는 12.6 kHz를 입력하면 같은 값입니다. 형식이 잘못되었거나 지원 범위를 벗어나면 “Unsupported value.”라고 알리고 적용하지 않습니다. 입력을 수정하거나 Escape로 취소합니다.

선택하거나 입력한 값은 Enter로 적용하고 Escape로 취소합니다. Tab으로 이동하면 입력 중인 값은 적용되지 않습니다. 체크박스는 Space로 전환합니다.

사용할 수 없는 컨트롤은 숨겨지고 관련 설정이 바뀌면 다시 나타납니다. 숨겨진 컨트롤의 단축키를 누르면 현재 포커스를 유지합니다. 외부 변경은 입력 중인 초안을 덮어쓰지 않습니다. Options > Application write lock(Alt+L)은 새 변경과 아직 전송을 시작하지 않은 대기 입력을 막습니다. 값 읽기는 유지하며 잠금을 풀어도 취소된 입력을 다시 보내지 않습니다. Edit > Cancel current operation도 대기 입력을 취소합니다. 두 기능 모두 이미 콘솔에 보낸 변경을 되돌리지는 않습니다.
