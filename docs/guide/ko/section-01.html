WING Access · 목차 · English

1. 시작과 연결

  1. ZIP 전체를 쓰기 가능한 폴더에 풉니다.
  2. bin\WingAccess.exe를 실행합니다. Windows 10/11 x64와 .NET Framework 4.8이 필요합니다.
  3. File > Connect to console...을 엽니다. Auto discovery, 최근 연결한 콘솔 또는 직접 입력한 IPv4 주소로 연결합니다. 최근 연결 목록은 최대 10개입니다.
  4. 제목 표시줄과 상태 표시줄에 Connected to <이름> (<IP>)가 표시되는지 확인합니다.

처음에는 오프라인으로 시작합니다. 페이지를 탐색하고 연습용 값을 조작할 수 있습니다. 연결하면 콘솔의 현재 설정을 가져오며 연습용 값을 콘솔로 보내지 않습니다. File > Disconnect를 선택하면 오프라인으로 돌아갑니다.

자동 복구 중 콘솔 식별이 바뀌었거나 확인할 수 없다는 경고가 나오면 File > Connect to console...에서 연결할 콘솔을 다시 선택하십시오.

Help > User guide에서 가이드를 열 수 있습니다. F1은 현재 지정된 단축키를 표시합니다. 전체 기본 단축키 카탈로그는 4장에 연결되어 있습니다.
