10. 페이지 복사와 앱 프리셋

File > Copy page를 실행하고 대응하는 목적지 페이지에서 Paste page...를 엽니다. 파일로 보관하려면 Save WING Access page preset... / Load WING Access page preset... (.wapreset)을 사용합니다. 일반 스트립·Send 페이지가 대상이며 Mix·Faders 묶음 페이지는 지원하지 않습니다.

미리 보기에 Current·New value·Exclusion reason이 표시됩니다. 적용할 항목을 체크합니다. 연결·출력 라우팅·Phantom은 명시적으로 포함하지 않으면 제외합니다. 외부에서 바뀐 값은 건너뜁니다. 모델을 바꿀 때는 모델부터 적용한 뒤 파라미터를 다시 미리 봅니다. .wapreset은 WING Access의 파일 형식입니다.
