15. Library와 콘솔 저장소

Library 트리에서 로컬 파일, 선택한 WING USB DATA 폴더와 스냅샷·프리셋·스니펫·Show 도구를 엽니다. File > Choose console storage (USB DATA)...는 이 컴퓨터에 연결된 폴더를 선택합니다. 네트워크로 콘솔의 USB 디스크를 탐색하는 기능은 아닙니다. 선택한 파일에 페이지의 Import·Copy·Open·Load 작업을 사용하십시오.

로컬 파일의 기본 위치는 패키지 안의 library 폴더이며 다른 위치를 선택해 저장할 수도 있습니다. 파일 저장 위치와 관계없이 앱 설정은 패키지 내부에 남습니다.

Library > Built-in library에서 DAW 제어 프리셋을 선택하고 Load selected preset...을 누릅니다. 불러오기 옵션을 확인한 뒤 적용하십시오. Clear DAW control assignments는 DAW 제어 할당을 비웁니다. 현재 설정을 별도로 보관하려면 File > Snapshots > Save WING snapshot as...를 사용하십시오.
