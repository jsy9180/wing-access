7. Mix, Sends와 Faders

스트립의 Bus Sends·Main Sends·Matrix Sends에서 Send on·Send level과 사용 가능한 Send mode/tap을 조작합니다.

목적지 스트립의 Mix는 들어오는 소스를 Channels 1–16부터 뱅크로 묶습니다. 각 소스에 Send on과 Send level이 있습니다. 소스를 펼치면 추가 설정이 나타나며 상위의 레벨 컨트롤은 상세 페이지에 중복하지 않습니다.

Faders는 특정 Mix 목적지와 관계없이 스트립의 Fader와 Mute를 모아 둔 페이지입니다. Mix와 Faders는 Tab 이동을 줄이기 위해 미터 컨트롤을 넣지 않으며 Alt+M으로 관련 미터를 읽을 수 있습니다. 기본 레이어는 4장의 페이지 규칙을 따르고 사용자 레이어는 등록한 대상으로 바로 이동합니다.
