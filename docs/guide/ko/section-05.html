5. 스트립 Home과 Config

트리에서 스트립을 선택하면 Home이 열립니다. 이름·색상·아이콘, 소스 선택, Source gain·Phantom 등 스트립 설정은 Config에 있습니다. Source group을 Enter로 적용한 뒤 갱신된 Source number 목록에서 선택하십시오.

Config의 DCA assign과 Mute group assign 버튼은 그룹 체크박스를 엽니다. 필요한 그룹을 체크하고 OK를 누릅니다. Cancel은 기존 할당을 유지합니다. 지정한 스트립 이름은 트리와 Fader·Mute에도 표시됩니다. 색상·아이콘은 현재 숫자 ID로 입력합니다. Home에는 자주 조작하는 컨트롤을 모아 두었습니다.
