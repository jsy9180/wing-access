5. 스트립 Home과 Config

트리에서 스트립을 선택하면 Home이 열립니다. 이름·색상·아이콘, 소스 선택, Source gain·Phantom 등 스트립 설정은 Config에 있습니다. Source group을 적용한 뒤 Source number를 선택하십시오.

Config의 DCA assign과 Mute group assign 버튼은 그룹 체크박스를 엽니다. 이미 할당된 그룹은 체크되어 있습니다. 체크를 추가하거나 해제한 뒤 OK를 누릅니다. Cancel은 기존 할당을 유지합니다. 지정한 스트립 이름은 트리와 Fader·Mute에도 표시됩니다. 색상·아이콘은 현재 숫자 ID로 입력합니다. Home에는 자주 조작하는 컨트롤을 모아 두었습니다.

DCA 또는 뮤트 그룹 페이지에서 Members...를 열어 여러 대상을 한 번에 할당합니다. 기존 멤버는 체크되어 있습니다. 체크를 추가하거나 해제한 뒤 Apply를 누릅니다. 뮤트 그룹에서는 소스도 선택할 수 있습니다. 항목에는 대상 종류와 번호가 함께 표시됩니다. Cancel은 기존 할당을 유지하며, Undo는 적용한 변경을 함께 되돌립니다. 다른 그룹 할당은 유지합니다. Config 또는 Source의 Copy customization...에서 이름· 색상·아이콘을 선택해 소스와 채널 사이에 복사합니다. Config에서는 Primary 또는 Alternate를, Source에서는 채널을 고릅니다. 필요할 때 Unlink channel customization을 직접 체크합니다.
