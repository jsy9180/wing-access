16. Connection and synchronization

Connection reads the console's current settings before reporting Connected. Changes from the console or another client update displayed values without moving your working page. Options > Announce external changes controls their announcements.

While recovering a connection, writes pause. Failed recovery displays Console disconnected. Check the connection and use File > Connect to console... again. Unconfirmed edits are not automatically replayed. Meter/snippet recording does not resume automatically; retained results remain available in the same session.
