10. Copy, paste and Undo

Use Ctrl+C or Edit > Copy settings, then Ctrl+V or Edit > Paste settings.... In the navigation tree, Copy includes the selected page and its subpages. On a parameter control it copies one applied value. Text being edited uses normal text copy and paste. Pasting multiple settings asks for confirmation.

Copy a strip to another strip of the same kind: Channel to Channel, Bus to Bus, and so on. The destination keeps its name, colour, icon, input settings and Inserts. Fader, Mute, processing, Sends and DCA/mute-group assignments are copied. EQ, Gate and Dynamics models change to match the copied processing settings.

A Mix page can be pasted into the same kind of destination, such as Main 1 Mix to Main 4 Mix or Bus 1 Mix to Bus 3 Mix. Copying a group includes only that group. Faders pages cannot be copied as a whole; individual Fader values can be copied. Bus Sends, Main Sends and Matrix Sends remain separate. Fader and Send level values cannot be pasted into each other.

Processing sections must have matching purposes. Copying one processor parameter requires the same model. FX slot copies include the model and its parameters; the destination slot must support that model. Insert assignments must be selected directly on the destination strip. Read-only information and commands are not copied.

Press Ctrl+Z or choose Edit > Undo to undo the last settings action. Held-arrow adjustments are one action; separate checkbox changes remain separate actions. A paste, batch edit or processor reset is one action. Options > Undo history size selects 10 to 100 actions in steps of ten; the default is 100. During text entry, Ctrl+Z undoes text.

If a setting has changed externally, Undo stops and clears the history. Subsequent edits start a new history. History is also cleared when changing console sessions or closing the app. Console commands that cannot be recorded also clear history. Playback, file operations and console commands cannot be undone. If Undo is interrupted, already-restored values remain applied.

File > Page presets > Save WING Access page preset... saves a .wapreset. Save WING Access page and subpage preset... includes subpages. Load WING Access page preset... opens a comparison before applying selected values. These file presets use their own recall scope; the clipboard's input and identity exclusions do not change them.
