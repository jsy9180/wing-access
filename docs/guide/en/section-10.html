10. Copy pages and use app presets

Choose File > Copy page, move to a matching destination page, then Paste page.... To keep a page in a file, use Save WING Access page preset... / Load WING Access page preset... (.wapreset). Use ordinary strip or send pages for these commands; aggregate Mix and Faders pages are not supported.

The preview lists Current, New value and Exclusion reason. Check the entries to apply. Connections, output routing and phantom are excluded unless you include them. Externally changed entries are skipped. Apply a model change first, then preview its parameters again. A .wapreset is a WING Access format.
