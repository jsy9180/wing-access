13. Snippets

Navigate > Library pages > Snippet recorder opens the recorder page. Start recording collects changes received from the whole console, including other controllers. Stop recording keeps the final value of each changed parameter. Save snippet as... writes .snip.

Edit recorded items... keeps checked entries. Edit > Add current page to snippet adds that page's values. Update recorded values refreshes retained entries. Open snippet... opens a file for editing; Load snippet applies it with global safes.

Disconnect stops recording and keeps collected entries. Reconnect does not restart it. Offline recording uses practice changes. Save the snippet before closing. Snippet recording stores parameter changes, not audio or timed playback automation.
