3. Edit values

For a slider, use Up/Right to increase and Down/Left to decrease. Faders and Send level use 0.1 dB steps, PageUp/PageDown uses 1 dB, and Shift+arrows uses 0.01 dB. Other sliders use their own steps; PageUp/PageDown uses ten steps. Home/End moves to the minimum/maximum. Shift+PageUp/PageDown remains page navigation.

Type to replace a slider value, or press Enter to edit its current value in place. Enter applies the text; Escape cancels it. Use -inf for a fader's minimum. Ctrl+A/C/V/X/Z work normally in the editor. Tab leaves an unfinished edit unapplied. Mouse dragging applies a slider value when you release the mouse.

Units are optional: enter 12600 or 12.6 kHz for the same frequency. If an entry is invalid or outside the supported range, “Unsupported value.” is announced and nothing is applied. Correct the entry, or press Escape to cancel.

Press Enter to apply a selection or text entry; Escape cancels it. Tab moves on without applying an unfinished edit. Space toggles a checkbox.

Unavailable controls are hidden and return when the relevant settings change. Shortcuts to hidden controls leave focus in place. External updates do not replace an unfinished edit. Options > Application write lock (Alt+L) blocks edits from this application and cancels queued edits whose transmission has not started. Reading remains available. Unlocking does not resend cancelled edits. Edit > Cancel current operation also cancels queued edits. Neither operation undoes changes already sent to the console.
