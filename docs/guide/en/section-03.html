3. Edit values

For a slider, use Up/Right to increase and Down/Left to decrease. Faders and Send level use 0.1 dB steps, PageUp/PageDown uses 1 dB, and Shift+arrows uses 0.01 dB. Other sliders use their own steps; PageUp/PageDown uses ten steps. Home/End moves to the minimum/maximum. Shift+PageUp/PageDown remains page navigation.

Type to replace a slider value, or press Enter to edit its current value in place. Enter applies the text; Escape cancels it. Use -inf for a fader's minimum. Ctrl+A/C/V/X/Z work normally in the editor. Tab leaves an unfinished edit unapplied. Mouse dragging applies a slider value when you release the mouse.

Combo boxes and text fields apply with Enter. Selecting a combo option or moving away with Tab does not apply it; Escape restores the received value. Space toggles a checkbox. Buttons perform their named action. Read-only controls cannot be edited.

Unavailable controls are hidden and return when the relevant settings change. Shortcuts to hidden controls leave focus in place. External updates do not replace an unfinished draft. If a model or source change invalidates that draft, use F5 and enter the value again. Options > Application write lock (Alt+L) blocks edits from this application. Other controls can still be read.
