15. Library and console storage

The Library tree provides local files, a selected WING USB DATA folder, snapshot, preset, snippet and show tools. File > Choose console storage (USB DATA)... chooses a folder mounted on this computer. It does not browse the console's USB disk over the network. Use the page's Import, Copy, Open and Load actions for the selected file.

Local files default to the package's library folder. You may save to another chosen location. Application settings remain inside the package regardless of that choice.

Library > Built-in library offers DAW control presets. Select one, choose Load selected preset..., review the recall options and confirm. Clear DAW control assignments clears those assignments. Use File > Save WING snapshot as... to save your current settings separately.
