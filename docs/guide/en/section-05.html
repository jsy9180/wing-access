5. Strip Home and Config

Select a strip in the tree for Home. Use Config for its name, color, icon, input selection, source gain/phantom and other strip setup controls. Apply the source group before choosing its source number.

Config's DCA assign and Mute group assign buttons open checkboxes for the groups. Check the required groups and choose OK; Cancel leaves assignments unchanged. Named strips use their names in the tree, Fader and Mute controls. Color and icon currently use numeric IDs. Home keeps the frequently used controls together.

On a mute group page, Members... edits that group's strip and source assignments. Other group assignments are retained. Copy customization... on an input Config or Source page copies selected Name/Color/Icon fields in either direction. From Config, select Primary or Alternate; from Source, select the channel. Explicitly check Unlink channel customization when needed.
