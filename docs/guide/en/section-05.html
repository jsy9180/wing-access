5. Strip Home and Config

Select a strip in the tree for Home. Use Config for its name, color, icon, input selection, source gain/phantom and other strip setup controls. Apply the source group before choosing its source number.

In Config, open DCA assign... or Mute group assign... to change group membership. Open Talkback assignments... to choose which Talk button unmutes or solos the strip. Existing assignments are checked. Change the checks you need and choose OK.

To choose which channels and auxes follow the global MAIN/ALT switch, open Console > Batch editing > Global input selection members... and choose Apply. New members follow the current switch position as soon as you apply.

Named strips use their names in the tree, Fader and Mute controls. Color and icon currently use numeric IDs. Home keeps the frequently used controls together.

On a DCA or mute group page, open Members... to assign several targets at once. Existing members are checked. Add or clear checks and choose Apply; mute groups also offer sources. Names include the target type and number. Cancel leaves assignments unchanged, and Undo reverses the applied changes together. Other group assignments are retained. Copy customization... on an input Config or Source page copies selected Name/Color/Icon fields in either direction. From Config, select Primary or Alternate; from Source, select the channel. Explicitly check Unlink channel customization when needed.
