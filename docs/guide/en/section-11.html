11. Snapshots and Scope

File > Snapshots > Save WING snapshot as... saves current settings to .snap. Offline capture saves practice settings. Update current snapshot replaces that file and retains a .bak backup. Choose the contents to update in the Update scope dialog. File > Snapshots > Edit snapshot scope... changes a file's Scope without recall.

File > Snapshots > Load WING snapshot... offers Normal Load or Restore all values. Review the recall Scope and the option to include connections, output routing and phantom before applying. Normal Load preserves the current global safes and clock settings. Ignore global safes bypasses the current safes for this load only. Temporary Load and Update scopes do not change the file's saved Scope. Restore all values bypasses the saved Scope and global safes, and can replace the safes and clock settings with values stored in the file.

The Scope dialog uses a check tree for targets and contents. Space checks a node and its children. Partly selected branches show a count. Content selections apply to the checked strips. OK accepts; Cancel leaves the selection unchanged.

During recall, unrelated controls remain available. Controls included in the recall are temporarily blocked. Read the results if application stops or an entry cannot be applied. Changes already applied remain in place.
