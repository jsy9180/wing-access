8. Routing, Setup and batch editing

Use Routing for source and output patches, Setup for console settings, and the monitor/talkback/recorder pages for those controls. Physical I/O lists follow the connected model. Options > Offline console model selects the practice model. User Patch > Signal patch > Open source jumps to its assigned original source.

For monitoring, open MONITOR / TALKBACK / OSCILLATOR > Monitors. Monitor destination, Dim, Mute, Mono and Swap left and right are on this page. Open Monitor A or Monitor B for its levels, Dim attenuation and Limiter threshold; Pan and Width are in EQ, and Polarity invert is in Polarity / delay.

In SETUP, Audio contains clock, USB audio and mute preferences. Audio > Solo system contains Solo mode, tap choices and Solo follow/selection preferences. General preferences includes Brightness. Surface > Metering contains meter tap settings; Surface > Surface preferences contains fader and display behavior. RTA settings and its RTA display child contain the console's analyzer settings.

Console > Batch editing > Routing...:

  1. Check destinations in the target tree.
  2. Choose Sequential sources or Same source, then Source group and First source.
  3. Optionally enable Show planned patches, then choose Apply.

Console > Batch editing > Sends...:

  1. Select a bus, Main or Matrix destination and check source strips.
  2. Leave settings at Keep, or select On / Off or Set value as appropriate.
  3. For Send level or Send pan, you can copy each source's current Fader or Pan.
  4. Choose Apply. Valid unfinished numeric entries are included.

Source properties... uses the same target tree and Keep/Set controls for source settings. Preamp remote assignments... limits the settings to remote assignments and received customization. Clear remote assignments prepares Off for the displayed sources; Apply is still required. Customization links... edits channel links in bulk.

A target change preserves your draft. Unavailable or incompatible edits must be corrected before Apply. Cancel before Apply sends nothing; during Apply it stops unsent changes. Already-applied changes remain in place. If settings changed externally, reopen the dialog to refresh its starting values before trying again.

On a console fader layer page, Edit assignments... lists Slot, Type and Target. Move up/down and Swap with slot exchange two positions. Clear slot leaves an empty position; Clear layer prepares all positions as Off. Apply saves, Cancel discards. These assignments are separate from the application's keyboard layers.

Choose Edit network addresses... to enter the complete IP address, subnet mask and gateway, then Save. Cancel leaves them unchanged. In DHCP the dialog fields are labelled Stored static and remain editable. Choose Apply network settings and confirm when you want to activate the stored settings. Reconnect using the new address if needed. Read Current IP address to check the address in use; Refresh network address updates this read-only value.

Console management

Open SETUP > Console management. Choose Lock console... and confirm to prevent console editing. The title bar and connection status show locked. Values and meters continue to update; navigation and local file editing remain available.

Choose Unlock console or press Ctrl+Alt+L. WING Access announces Console unlocked only after confirmation from the console. If unlocking fails, enable remote write access or unlock on the console. Existing customized shortcuts take priority; check Help > Keyboard shortcuts if Ctrl+Alt+L is assigned elsewhere. Options > Application write lock (Alt+L) remains a separate application setting.

Surface lock shows the console's surface-lock status. Save console state saves the current state; Disable console autosave controls automatic saving.

Console fader assignments

Open SETUP > Surface > Console fader layers, choose the surface section, layer and Fader slot. Apply Assignment type, then set the available assignment fields. Strip and DCA targets, Send sources and destinations, and FX slots are listed by name. FX parameter and MIDI indices use numeric entry. MIDI assignments also expose MIDI value.

These pages configure console slots. The Faders page, keyboard layers and strip bookmarks continue to address their named logical strips. A bookmark saved on a console assignment page returns to that slot's settings. Model-specific stored preferences are labelled Full-size, Compact or Rack; physical I/O and GPIO lists follow the selected model.
