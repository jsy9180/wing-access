8. Routing, Setup and batch editing

Use Routing for source and output patches, Setup for console settings, and the monitor/talkback/recorder pages for those controls. Physical I/O lists follow the connected model. Options > Offline console model selects the practice model. User Patch > Signal patch > Open source jumps to its assigned original source.

Actions > Batch routing...:

  1. Choose Select destinations... and check the required targets.
  2. Select Sequential sources or Same source.
  3. Select Source group and First source; review Planned patches.
  4. Choose Apply. Cancel sends nothing.

Actions > Batch bus feeds...:

  1. Choose Destination bus and Select sources....
  2. Choose Setting, then enter or select its value. Press Enter to stage it.
  3. Choose Apply to send the changes.

Batch results identify conflicts and failures. Already-applied changes are not rolled back. A destination changed externally after selection is skipped.

On the network settings page, Stored static IP address, subnet mask and gateway remain editable in DHCP. Enter each octet and press Enter. Static mode removes the Stored static prefix. Current IP address is read-only; opening the page or choosing Refresh network address updates it. Unavailable means the query failed; Not connected means offline. Current lease mask/gateway are not displayed.
