2. Navigate

The main window has one navigation tree and the selected page's controls. Use the arrow keys to browse the tree. Tab moves through the page controls; Shift+Tab moves back. Each launch starts with the tree collapsed at Channels.

  • Ctrl+1: focus the tree at the current page.
  • Ctrl+2: collapse other branches while keeping the current path open.
  • Ctrl+`: leave the page, collapse all branches and focus its top-level tree item.
  • Ctrl+PageUp / Ctrl+PageDown: previous / next strip, keeping the corresponding page and control when available.
  • Shift+PageUp / Shift+PageDown: previous / next sibling page.
  • Ctrl+Alt+F: find a parameter by a known name or an exact parameter path.
  • F5: refresh the current page. F6: read the focused value.
  • Shift+F11: read the working context and active keyboard bank.

After a layer or bookmark jump, the destination control receives focus first. The tree then selects that page without an extra announcement. Ctrl+1 returns there. A jump announces the target and enough page context to distinguish it; normal Tab navigation uses shorter control names.

The console's screen selection does not move your working page. Ctrl+F2 explicitly moves to its selected strip. Actions > Select this strip on the console performs the reverse action. Name search covers the pages the application already knows.
