4. Layers, bookmarks and shortcuts

Default key pattern

Ctrl+Alt+letter opens a strip page: H Home, C Config, G Gate, E EQ and D Dynamics. B/M/X opens Bus/Main/Matrix Sends. I opens Mix on a bus, Main or Matrix. Ctrl+Alt+Shift+G/D opens the matching Gate/Dynamics sidechain page. Ctrl+letter moves to a control; on Config, Gate and Dynamics, the page's own bindings take priority. Ctrl+function keys toggle strip settings. Ctrl+Shift+F1–F8 opens console sections; Ctrl+Shift+F10 opens Monitor / Talkback / Oscillator. The complete list below shows every default and its context.

Existing custom assignments take priority over these defaults. The combined Mix / Main Sends command remains available for custom assignments.

Layers and banks

A keyboard layer groups targets; each bank holds eight positions. Changing the bank changes the assignments of Shift+F1–F8. It does not change console values or move the working page until you press a position key.

  • Shift+F1–F8: select position 1–8 in the current bank.
  • F7 / F8: previous / next bank. These stop at the first and last bank.
  • F9 / Shift+F9: next / previous layer, cycling through the available layers.
  • F2: choose a bank. Search by layer name, bank label or displayed range, select a row and press Enter. Escape cancels. Your page, focus and unfinished edit remain.
  • Shift+F11: read the current working context and bank.

Default layers contain:

  • Inputs: Channels 1–8, 9–16, 17–24, 25–32, 33–40, then Aux 1–8.
  • Buses: Buses 1–8 and 9–16.
  • Main / Matrix: Mains 1–4, then Matrices 1–8. Main positions 5–8 are empty.
  • DCAs: DCAs 1–8 and 9–16.
  • Effects: FX 1–8 and 9–16.
  • Mute groups: groups 1–8. Selecting a position focuses Mute without changing it.

Example: press F2, find Inputs — Channels 25–32, press Enter, then Shift+F3 to select Channel 27. Aux belongs to Inputs; use F7 to return to its channel banks. F2 selects banks only. Use the navigation tree or Ctrl+Alt+F for pages/parameters.

Standard positions follow the working page:

  • On a strip page, select the corresponding page/control of another strip.
  • In Mix, keep the destination and focus the selected source's Send level.
  • In Sends, keep the source and focus the selected destination's Send level.
  • In Faders, focus the selected strip's Fader.
  • In FX, keep a parameter position only when the models match.

Mix, Sends and Faders offer only usable standard banks. Empty and unavailable positions keep their slot numbers. Pressing one leaves focus in place. Opening these pages aligns the bank with the focused target. Tab and incoming updates do not change banks. To leave this restricted context quickly, press Ctrl+`, then F2. Each launch starts at Inputs — Channels 1–8.

User layers

User layers hold your own sequence of strips, FX slots and mute groups. They are available on every page. A user position jumps directly to its strip Home, FX slot or mute group, including from Mix and Faders. It is not a relative send shortcut.

To build a layer as you work:

  1. Focus the target and press Ctrl+Alt+U.
  2. Choose a user layer the first time, or enter a name to create one.
  3. Repeat Ctrl+Alt+U on other targets. The first empty slot is used; a full layer gains another bank. A duplicate is announced at its existing position.

In Mix, quick-add saves the focused source; in Sends it saves the destination; in Faders it saves the strip. Options > User layers > Quick-add layer changes the destination for future quick additions. The selected user bank stays active after a jump.

Options > User layers > Edit user layers... provides New, Rename, Delete layer and Copy current bank. Add targets opens a grouped check tree for multiple selections. The position list reads Bank / Slot / Target. Clear slot leaves a hole. Move up/down, Ctrl+Up/Down and Move to swap slots rather than shifting the remaining targets. You may add a target more than once in this editor. OK saves the changes; Cancel discards them. Use bookmarks for a specific page or parameter instead of a whole target.

Bookmarks

Bookmarks save a page and focused control, not its value. There are ten slots. Use the top-row keys, not the numeric keypad. The Bookmarks menu recalls locations; its Save current location submenu stores them. An unavailable saved parameter falls back to its page.

Customize shortcuts

Options > Edit keyboard shortcuts... contains the complete command catalog, including unassigned commands. Commands are grouped by task: navigation, keyboard layers, strip controls, meters, playback, library operations and settings. Browse the category tree or use Find command. Select a command, focus New shortcut, press the keys and choose Assign. Remove shortcut leaves a command unassigned. Page-specific commands apply on their named page.

A conflict dialog identifies the affected commands. Overwrite removes their keys; it does not assign replacements. Restore selected default resets one command; Restore to defaults resets the whole set after confirmation. OK saves; Cancel cancels the editing session. An external screen-reader key warning does not change that reader's settings. Keep reader and application assignments consistent.

Options > Main shortcut destination selects Main 1–4 for Shift+F12 and other commands labelled Selected Main. This preference does not change routing. F1 always shows your current assignments, while the HTML catalog lists defaults.
