1. Start and connect

  1. Extract the complete ZIP into a writable folder.
  2. Run bin\WingAccess.exe. Windows 10/11 x64 and .NET Framework 4.8 are required.
  3. Choose File > Connect to console.... Select Auto discovery, a recent console, or enter an IPv4 address. The list retains up to ten successful connections.
  4. Wait for Connected to <name> (<IP>) in the title and status bar.

The application starts offline. You can explore pages and edit practice values. Options > Offline console model selects the model used for initial practice settings. Connecting reads the console's current settings; it does not upload the practice values. Use File > Disconnect to return to offline operation. If automatic recovery reports a changed or unverifiable console identity, use File > Connect to console... to select the intended console again.

Help > User guide opens this guide. F1 shows your current keyboard assignments. The complete default shortcut catalog is linked from chapter 4.

Menus

File groups snapshots, presets, shows and playlists in submenus. Edit contains Undo, copy/paste, processor reset and strip assignments. Navigate contains tree and page movement; Navigate > Keyboard banks selects layers and banks. Console contains console actions and batch routing. Metering contains meter reading and recording. Options contains application preferences and User layers. Bookmarks recalls saved locations; Bookmarks > Save current location stores them. Help opens guides and shortcuts.
