17. Settings, updates and troubleshooting

Settings, shortcuts, bookmarks, user layers and recent consoles are stored in user-data/settings.json inside the package.

To update or move WING Access:

  1. Close the application and extract the new package into a writable folder.
  2. Copy user-data and library from the previous package.
  3. Run the new bin\WingAccess.exe. Keep the old copy until you have checked your files.

A damaged settings file uses settings.json.bak. If both files are unusable, defaults are loaded. To start with defaults, close the app and move settings.json elsewhere. A settings save error is reported; the application does not switch storage paths.

If a key does not work, check F1 and Options > Edit keyboard shortcuts, including screen-reader conflicts. If a model/source changed during an edit, refresh with F5. If a control is unavailable, check its page and current settings. If a file will not save, check folder access and any missing or conflicting referenced files.

For a problem report, include the application version, console model/firmware, page/control, steps to reproduce and whether it occurs offline. Remove personal addresses and show content before sharing diagnostic information.
