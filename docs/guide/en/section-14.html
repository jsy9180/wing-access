14. Shows and playlists

File > Shows > New WING show... / Open WING show file... opens the show editor. Add snapshot, snippet, WAV or strip/FX preset files. Rename, reorder or remove scenes and edit Skip/Link, tags and MIDI text as needed. For a preset scene, choose its destination and Scope; Edit scene destination and scope... changes them later.

Save preset and add scene... saves the selected target and registers it in the show. File > Shows > Save preset and add to show... offers the same action. Cancelling the scene registration does not delete a preset that was already saved.

Save/Save as copies referenced assets alongside the .show. Resolve missing files or different files with the same name before saving. Load selected scene... applies a snapshot, snippet or preset. To activate the saved show, open it on the console. Navigate > Library pages > Console show and scenes lists the console's active show and its scene actions.

File > Playlists > New WING playlist... / Open WING playlist... edits .plist files. Add WAV files, edit Song name, Skip, Stop after this song and Repeat playlist, then use Move up/down or Remove as needed. Save chooses a destination and copies the WAVs alongside it. Cancelling the location dialog or a failed save returns to your edits. Cancel in the editor discards them. Open the saved playlist on the console; the application has no PC playback or remote playlist activation command.
