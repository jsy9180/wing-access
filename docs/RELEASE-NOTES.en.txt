WING Access 1.1.0
2026-11-14
=================

- Added console lock and unlock commands, with Ctrl+Alt+L to unlock and a visible locked status.
- Improved model-specific controls and named targets for console fader assignments.
- Added an IP address, subnet mask and gateway editor with confirmation before applying network settings.
- Improved console identification and name updates during reconnection.
- Grouped console state saving and autosave settings under Console management.
- Snapshot and snippet recalls preserve the current RTA source, tap, decay and detector settings.
