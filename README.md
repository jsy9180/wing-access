# WING Access

Keyboard and screen-reader control for the Behringer WING family, developed by **Seongyyeol Jang**.

[Download 1.1.0](https://github.com/jsy9180/wing-access/releases/tag/v1.1.0) · [Report a problem](https://github.com/jsy9180/wing-access/issues)

## Start

Windows 10/11 x64 and .NET Framework 4.8 are required. Extract the complete ZIP into a writable folder and run `bin\WingAccess.exe`. Connect through **File > Connect to console...**, or explore offline. Open `docs/index.html` in the downloaded package for the English/Korean guides and shortcut catalog.

The app includes a navigation tree, eight-position keyboard banks, user layers, bookmarks, editable sliders, meter readings/recording and library tools.

## Testing status

WING Access has been tested through actual use with NVDA and Sense Reader. Testing with physical WING series consoles is not yet complete. WING Access is substantially implemented, but still needs additional testing with actual WING, WING Compact and WING Rack consoles.
