# WING Access

Keyboard and screen-reader control for the Behringer WING family, developed by **Seongyyeol Jang**.

[Download 1.2.3](https://github.com/jsy9180/wing-access/releases/tag/v1.2.3) · [Report a problem](https://github.com/jsy9180/wing-access/issues)

## Start

Windows 10/11 x64 and .NET Framework 4.8 are required. Extract the complete ZIP into a writable folder and run `bin\WingAccess.exe`. Connect through **File > Connect to console...**, or explore offline. Open `docs/index.html` in the downloaded package for the English/Korean guides and shortcut catalog.

Keyboard banks, user layers and bookmarks provide quick access to your controls. Copy settings to compatible targets and undo recent edits. Meter readings, recording summaries and library tools are also included.

## Testing status

WING Access has been tested through actual use with NVDA and Sense Reader. Testing with physical WING, WING Compact and WING Rack consoles is not yet complete; further console testing is needed.
